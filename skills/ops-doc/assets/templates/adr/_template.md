# NNNN - Titre de la décision

> Modèle inspiré de MADR (adr.github.io/madr). Un ADR **ne se modifie pas** une fois accepté : si la décision change, on écrit un nouvel ADR qui le remplace.

- **Statut** : proposé / accepté / remplacé par [NNNN](NNNN-xxx.md)
- **Date** : AAAA-MM-JJ
- **Décideurs** : ...

## Contexte
Le problème, les contraintes, ce qui force à décider maintenant.

## Options envisagées
1. Option A
2. Option B
3. Option C

## Décision
On choisit **l'option X**, parce que...

## Conséquences
- **Gain** : Ce qu'on gagne
- **Coût** : Ce qu'on accepte de perdre ou de devoir gérer
- Ce que ça implique de faire (doc, alertes, procédures)
